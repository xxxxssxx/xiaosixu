## Selected Projects

- [Cloud–Edge Collaborative CKM Construction](https://github.com/xxxxssxx/Cloud-Edge-Collaborative-CKM-Construction) — Research code for a cloud-trained score-based CKM prior and diffusion posterior sampling for construction from noisy, irregular observations.
- [CKM_batching](https://github.com/xxxxssxx/CKM_batching) — Simulation code for PPO-based joint optimization of uplink transmission and cloud-side batching in wireless LLM services, with CKM-assisted control.
- [gptq-reproduction](https://github.com/xxxxssxx/gptq-reproduction) — Reproduction of selected GPTQ experiments on OPT-125M, OPT-13B, and OPT-30B, including 3-bit quantization, CUDA kernel tests, experiment logs, and lazy-batch-size analysis.
